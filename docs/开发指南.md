## 3. 一次上传请求的完整流转

家长在小程序点「提交给老师」之后发生了什么：

```
[小程序] miniprogram/pages/upload/upload.js
   wx.uploadFile → POST /api/homework/upload
         ↓
[路由] backend/routes/homework.py :: upload_homework()
   1. 校验角色是 parent
   2. 校验这个家长确实在这个班（查 Membership 表）
   3. 读文件字节，大小不超过 100MB
         ↓
[服务] backend/services/storage.py :: save_upload()
   落盘到 data/uploads/20260821/<uuid>.jpg
         ↓
[路由] 回到 homework.py
   4. 往 homework 表插一行，is_homework=0（待处理）
   5. background.add_task(_process_async, ...)  ← 异步，立刻返回
   6. HTTP 200 返回给小程序（此时还没有点评）
         ↓
━━━━━━━ 以下在后台线程跑，小程序已经收到响应了 ━━━━━━━
         ↓
[异步任务] backend/routes/homework.py :: _process_async()
         ↓
[服务] backend/services/ai_pipeline.py :: process_homework()
   ├─ 图片 → media/image.py 压缩
   ├─ 视频 → media/video.py 用 ffmpeg 抽 6 帧
   │         + 抽音轨 → OSS 上传 → Paraformer 转写
   ├─ 分类：这是不是作业？ai/vision_router.py → 通义千问 VL
   ├─ 点评：ai/openai_vl_client.py + prompts/grader.py
   └─ 润色：ai/deepseek_client.py → 火山方舟
         ↓
   回写 homework 表：is_homework=1, feedback=<点评>
         ↓
[老师端] 下次拉列表就看到了
   GET /api/homework?class_id=X
```

**为什么用 BackgroundTasks**：AI 要跑 8~20 秒，不能让小程序一直等着转圈。相当于 Spring 的 `@Async`。

## 4. 常见开发任务

### 4.1 加一个新接口

以「老师给作业打星级」为例，三步：

**第一步：定义请求体**（≈ Java DTO）

`backend/routes/homework.py` 顶部已有一堆，照着加：

```python
class StarReq(BaseModel):
    stars: int          # 必填
    note: str = ""      # 可选，默认空串
```

对应 Java：
```java
public class StarReq {
    private int stars;
    private String note = "";
    // getter/setter...
}
```

**第二步：写接口**

```python
@router.post("/{hw_id}/star", response_model=HomeworkOut)
def set_star(hw_id: int, req: StarReq, user: User = Depends(current_user)):
    hw = Homework.get_or_none(Homework.id == hw_id)
    if not hw:
        raise HTTPException(404, "not found")
    if user.role != "teacher":
        raise HTTPException(403, "forbidden")
    hw.teacher_review = f"⭐{req.stars} {req.note}"
    hw.save()
    return get_homework(hw_id, user)
```

对应 Java：
```java
@PostMapping("/{hwId}/star")
public HomeworkOut setStar(@PathVariable Long hwId,
                           @RequestBody StarReq req,
                           @AuthenticationPrincipal User user) { ... }
```

对照表：

| FastAPI | Spring Boot |
|---|---|
| `@router.post("/{hw_id}/star")` | `@PostMapping("/{hwId}/star")` |
| `hw_id: int`（名字和路径占位符一致） | `@PathVariable Long hwId` |
| `req: StarReq`（类型是 BaseModel 子类） | `@RequestBody StarReq req` |
| `user: User = Depends(current_user)` | `@AuthenticationPrincipal User user` |
| `response_model=HomeworkOut` | 方法返回值类型 |
| `raise HTTPException(404, "...")` | `throw new ResponseStatusException(NOT_FOUND, "...")` |

**第三步：小程序调用**

`miniprogram/utils/api.js` 加一行：

```js
setStar(id, stars, note) {
  return request({ url: `/api/homework/${id}/star`, method: "POST", data: { stars, note } });
},
```

改完 `--reload` 会自动重启，去 http://127.0.0.1:8000/docs 就能直接点着测。

### 4.2 加一个数据库字段

ORM 是 SQLAlchemy 2.x（声明式），表在启动时 `Base.metadata.create_all()` 创建，**只建新表、不给已存在的表加列**。

第一步，在 `backend/models.py`（业务表）或 `ai_teacher/storage/models.py`（Child/Homework/GrowthMetric）里加字段：

```python
star: Mapped[int | None] = mapped_column(Integer, nullable=True)   # 新增
```

第二步分两种环境：

- **Oracle（生产）**：写一句 DDL 变更并执行，例如 `ALTER TABLE homework ADD (star NUMBER(10))`。以后表多了建议引入 Alembic。
- **本地 SQLite 开发库**：不想丢数据就在 `ai_teacher/storage/database.py` 的 `migrate_dev_sqlite()` 里照现有样子加一段幂等 ALTER；无所谓数据直接删 `data/ai_teacher.db` 重启重建。

字段类型对照（模型里一律按 Oracle 目标写）：

| SQLAlchemy | Java/JPA | Oracle | SQLite（本地） |
|---|---|---|---|
| `String(64)` | `String` | VARCHAR2(64 CHAR) | VARCHAR |
| `Text` | `String` (@Lob) | CLOB | TEXT |
| `Integer` | `Integer` | NUMBER(10) | INTEGER |
| `Float` | `Double` | BINARY_FLOAT/DOUBLE | REAL |
| `TIMESTAMP` | `LocalDateTime` | TIMESTAMP | DATETIME |
| `ForeignKey("app_user.id")` | `@ManyToOne` | NUMBER + FK | INTEGER + FK |
| `Integer, Identity(), primary_key` | `@Id @GeneratedValue` | GENERATED BY DEFAULT AS IDENTITY | INTEGER PK |

注意：字符串一律 `VARCHAR2(n CHAR)`（按字符计长，中文友好）；Oracle 里空串 `''` 等于 NULL，写入前归一成 None；`user` 是保留字，用户表叫 `app_user`。

### 4.3 改 AI 点评的风格（最常改的地方）

全在 `ai_teacher/prompts/grader.py`，**纯字符串，不用懂 Python 也能改**。

两个关键位置：

```python
SYSTEM_PROMPT = (
    "你是一名经验丰富的幼儿/小学低年级老师..."   # ← 改这里控制 AI 的"人设"和硬规则
)

def build_prompt(*, transcript=None, subject_hint=None):
    parts = []
    parts.append("【亮点】...")                     # ← 改这里控制输出格式
    return "\n".join(parts)
```

润色风格在 `ai_teacher/ai/deepseek_client.py` 的 `polish()` 方法里。

**改完怎么验证**（不用开小程序）：

```powershell
# 单个文件跑一遍完整链路
python scripts\demo_pipeline.py test\某作业.jpg

# 整个目录批量跑，输出对比报告
python scripts\batch_test.py test\
```

**血泪经验**（前面踩过的坑，改提示词时注意）：
- AI 不会主动承认"我看不清"，宁可编一个具体题号。想让它别编，得**明确禁止**，不能只说"请谨慎"
- 「建议再检查一遍」这种防御性套话要显式禁止
- 算术题的小字体超出视觉模型分辨率，**别指望它逐题批改**，只能评完成度和字迹

### 4.5 加一个小程序页面

四个文件一组，缺一不可（微信的规矩）：

```
pages/xxx/xxx.js      逻辑
pages/xxx/xxx.json    页面配置（标题等）
pages/xxx/xxx.wxml    模板（≈ HTML）
pages/xxx/xxx.wxss    样式（≈ CSS）
```

然后**必须**在 `miniprogram/app.json` 的 `pages` 数组里注册，否则跳转会静默失败（前面视频播放页就是这么踩的坑）。

页面骨架：

```js
const api = require("../../utils/api.js");

Page({
  data: { list: [] },              // 相当于 Vue 的 data

  onLoad(query) {                  // 页面首次加载，query 是 URL 参数
    // 注意：中文参数要 decodeURIComponent，否则显示成 %E5%B0%8F%E6%98%8E
    let name = query.name || "";
    try { name = decodeURIComponent(name); } catch (e) {}
  },

  onShow() { this.load(); },       // 每次页面显示（含返回时）

  async load() {
    const r = await api.listXxx();
    this.setData({ list: r });     // 改数据必须用 setData，不能直接 this.data.list =
  },
});
```

## 5. 数据库

生产用 **Oracle 19c+**（独立 schema 用户 `AIWECHAT`，经 `python-oracledb` 瘦模式连接，免装客户端）；本地开发默认 **SQLite**：`data/ai_teacher.db`。`config.yaml` 的 `database.dialect` 在两者间切换，同一套 SQLAlchemy 模型。引擎/session 封装在 `ai_teacher/storage/database.py`，全部 13 张表的唯一定义在 `backend/models.py`（核心三张在 `ai_teacher/storage/models.py`）。

**Oracle 建库/迁移**：

```powershell
# DBA 先执行 scripts/sql/01_oracle_schema.sql 建用户
python scripts/check_oracle.py               # 连通/权限自检
python scripts/check_oracle.py --dump-ddl    # 导出建表 DDL 给 DBA 审核
python scripts/migrate_sqlite_to_oracle.py   # 旧 SQLite 数据迁入 Oracle（源只读）
```

**本地 SQLite 直接查**：

```powershell
python -c "import sqlite3; c=sqlite3.connect('data/ai_teacher.db'); [print(r) for r in c.execute('SELECT id, child_id, media_type, feedback FROM homework ORDER BY id DESC LIMIT 5')]"
```

或者装个 [DB Browser for SQLite](https://sqlitebrowser.org/) 图形化看。Oracle 用 SQL Developer 以 AIWECHAT 用户登录。

**表关系**：

```
app_user ─┬─< classroom (teacher_id)     老师建班
          └─< membership (user_id)       家长加入班级
                 │
classroom ─< membership (classroom_id)
       ├────< homework (classroom_id, 冗余 child_name)
       ├────< growth_checkin (classroom_id+child_name+date)
       │           └─< growth_checkin_item
       ├────< report_batch ─< child_report
       └────< growth_template(+option)

child ──────────< homework (child_id)    全局名字表（遗留；新业务按班级作用域）
```

**SQLAlchemy 2.x 查询 ↔ JPA 对照**（路由里 `db: Session = Depends(get_db)`）：

```python
from sqlalchemy import select, update, func

# 查单条，找不到返回 None（不抛异常）
hw = db.get(Homework, 5)                       # 按主键，≈ findById
hw = db.scalar(select(Homework).where(Homework.id == 5))

# 条件查询（多个 where 默认 AND）
rows = db.scalars(
    select(Homework).where(Homework.classroom_id == cid, Homework.is_homework == 1)
).all()

# 排序 + 分页
rows = db.scalars(
    select(Homework).order_by(Homework.created_at.desc()).limit(100)
).all()

# 插入
hw = Homework(child_id=child.id, media_type="image")
db.add(hw); db.flush()      # flush 后 hw.id 可用；请求结束统一 commit
# ≈ repository.save(new Homework(...))

# 更新（查出对象改属性，脏检查自动 UPDATE）
hw.feedback = "改后的点评"
db.commit()

# 批量更新
db.execute(update(Homework).where(Homework.id == 5).values(is_homework=0))

# 计数 / 存在
n = db.scalar(select(func.count()).select_from(Homework))
exists = db.scalar(select(Homework.id).where(Homework.msg_id == 123)) is not None
```

**Session/事务规则（重要）**：

1. 每个 HTTP 请求一个 session（`get_db()` 依赖），写路由显式 `db.commit()`。
2. **后台任务（BackgroundTasks）必须用 `session_scope()` 自建 session**，不依赖请求；且**调 AI 期间不持 session**——先取数关 session，调完再开新 session 写回（参考 `backend/services/report_service.py`）。
3. 权限判断、构造返回 JSON 都要在 session 关闭前完成；列表里需要关联对象（如老师名）用标量外键列 `classroom.teacher_id` 或 `selectinload/joinedload`，避免 DetachedInstanceError。
4. `Homework.id == 5` 里的 `==` 是 SQLAlchemy 重载运算符生成 SQL 条件，跟 JPA Criteria API 一个思路。

## 6. 配置和密钥

两个文件分工：

| 文件 | 放什么 | 进 git 吗 |
|---|---|---|
| `.env` | 密钥、微信 ID、限额、`ORACLE_PASSWORD` | ❌ 已 gitignore |
| `config.yaml` | 模型名、温度、抽帧数、路径、`database` 连接段 | ✅ 进 |

`config.yaml` 的数据库段：

```yaml
database:
  dialect: sqlite        # sqlite（本地） | oracle（生产，瘦模式直连 19c+）
  host: 127.0.0.1
  port: 1521
  service_name: XEPDB1   # 多租户库连 PDB，别连 CDB$ROOT
```

⚠️ **本项目 .env 里的密钥在开发过程中被贴到过对话里，建议全部去控制台轮换一次**（阿里百炼 key、火山方舟 key、OSS AccessKey）。

## 8. 部署到服务器

```bash
# 1. 装依赖
pip install -r requirements.txt

# 2. DBA 建好 Oracle 用户后（scripts/sql/01_oracle_schema.sql）：
#    .env 填 ORACLE_PASSWORD，config.yaml 改 database.dialect: oracle
python scripts/check_oracle.py
python scripts/migrate_sqlite_to_oracle.py   # 仅首次从 SQLite 切换时

# 3. 生产模式启动（多进程，去掉 --reload）
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --workers 4

# 4. 关掉开发登录后门（重要）
echo "ENABLE_DEV_LOGIN=0" >> .env

# 5. 填微信正式凭据
# WX_APPID=...
# WX_SECRET=...
```

前面加 Nginx 做 HTTPS（微信小程序强制要求 HTTPS），然后在微信公众平台后台配置「request 合法域名」。

**注意事项**：
- `--workers 4` 多进程模式下，`ai_teacher/utils/ratelimit.py` 的内存计数器会各算各的。真要限流得换成 Redis 或数据库计数
- 服务器时区固定 Asia/Shanghai，否则周报周一归一会错位；oracledb 瘦模式支持 Oracle 12.1+，11g 才需要 Instant Client
- BackgroundTasks 在服务重启时会丢正在跑的报告任务（启动时自动置 failed，老师重新生成即可），要可靠得换 Celery
- `data/uploads/` 会一直涨，要加定时清理（`ai_teacher/storage/db.py` 里有 `cleanup_old_cache()` 现成的）

## 9. 从哪开始读代码

建议顺序：

1. `scripts/e2e_backend_test.py` — 从测试看整个系统怎么用，最快建立全局印象
2. `backend/routes/homework.py` — 最核心的业务，上传和查询都在这
3. `backend/services/ai_pipeline.py` — AI 编排逻辑
4. `ai_teacher/prompts/grader.py` — 提示词，纯文本，理解产品逻辑
5. `ai_teacher/ai/openai_vl_client.py` — 看一个模型客户端长什么样
6. `miniprogram/pages/upload/upload.js` — 前端怎么发请求
